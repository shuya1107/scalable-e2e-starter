
A_B_Testing.tsで使ってるやつ

・表示がランダムなとき　
    解決策が二つ
    ・配列などに期待値の文字列を入れて比較をする
    →文字列さえ合っていればOKにしたいとき
    ・Cookieを登録して特定の文字列のみを表示させるように設定させる
    →設定したときに設定したものが表示されるかの確認　設定したものが表示されない→制御がちゃんとされていない可能性がある
    →ランダムで出てくる場合確実にそのページのテストを行うときに使う
    →実際に使われているCookieを登録して条件にあうユーザを作成する（ログインとかね）
    これらはCookieを開発の人に設定をしてもらわないとできないから頑張ろう！！

await page.context().addCookies([
    {
        // --- ここまでは今までと同じ（基本の4点セット） ---
        name: 'session_token',                // Cookieの名前（セッションIDなど）
        value: 'eyJhbGciOiJIUzI1NiIsInR...',  // ログイン成功の証となる暗号（JWTなど）
        domain: 'the-internet.herokuapp.com', // 有効なドメイン
        path: '/',                            // 有効なパス
        
        // --- ここから下が「セキュリティや寿命」を決める追加セット ---
        secure: true,       // 【超重要】「https://」の暗号化通信の時だけCookieを送る
        httpOnly: true,     // 【超重要】ブラウザのJavaScriptからこのCookieを読み取れなくする（ハッカー対策）
        sameSite: 'Strict', // 別のサイトのリンクから飛んできた時は送らない（Strict, Lax, None から選ぶ）
        expires: 1735689600 // 有効期限（※2025年1月1日などを「UNIXタイムスタンプ」という数字で指定する）
    }
]);
